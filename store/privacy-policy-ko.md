# QR 스캐너 개인정보 처리방침

큐비온(이하 "회사")은 QR 스캐너 앱(Android·iOS, 이하 "앱")과 실시간 스캔 확인 웹 서비스 scanview.app(이하 앱과 함께 "서비스")을 이용하는 분의 개인정보를 「개인정보 보호법」 등 관련 법령에 따라 처리하고 보호합니다. 이 방침은 앱 1.3.0 버전 기준이며 2026년 10월 16일부터 시행합니다.

## 1. 한눈에 보기

- 회원가입 없이 스캔, 코드 생성, 기록 관리 등 대부분의 기능을 쓸 수 있습니다. 이때 스캔 기록, 만든 코드, 스캔 사진, 설정은 **기기 안에만** 저장되고 회사 서버로 전송되지 않습니다.
- 앱에는 **광고가 없으며 광고 ID를 수집하지 않습니다.**
- 회사 서버(scanview.app)로 정보가 가는 경우는 ① 회원가입·로그인을 할 때, ② 로그인한 상태에서 **실시간 서버 전송**을 직접 켰을 때뿐입니다.
- 사용 분석(Firebase Analytics)은 Android에서 기본으로 켜져 있고 iOS에서는 기본으로 꺼져 있습니다. **설정 → 앱 정보 및 지원 → 사용 분석 동의**에서 언제든 끄거나 켤 수 있습니다.
- 계정과 서버 데이터는 앱에서 바로 탈퇴하거나 [계정 및 데이터 삭제 안내](https://scanview.app/legal/account-deletion) 페이지의 방법으로 삭제를 요청할 수 있습니다.

## 2. 처리하는 개인정보 항목과 수집 방법

### 2-1. 회원가입·로그인 (선택)

회원가입은 선택 사항이며, 실시간 서버 전송 기능을 쓰려면 로그인이 필요합니다.

- **이메일 가입:** 이메일 주소, 비밀번호, 이름(닉네임). 비밀번호는 복원할 수 없는 방식(솔트를 더한 scrypt 해시)으로만 저장합니다.
- **Google 로그인:** Google 계정의 이메일 주소, 이름, 프로필 사진 주소, Google 계정 고유 식별자
- **Apple로 로그인(iOS):** Apple이 전달하는 이메일 주소(사용자가 선택한 경우 Apple의 비공개 중계 주소), 이름(제공한 경우), Apple 계정 고유 식별자
- **자동 생성 정보:** 회원 번호, 로그인 유지용 인증 토큰, 앱이 만든 무작위 기기 식별자(로그인 기기 구분용이며 광고 ID나 하드웨어 식별자가 아님), 가입일, 마지막 로그인·접속 일시, 기능 잠금 해제 상태 기록

### 2-2. 실시간 서버 전송 (선택, 로그인 필요)

설정 → 실시간 서버 전송을 켠 경우에만, 스캔할 때마다 다음 정보가 scanview.app 서버로 전송·저장됩니다.

- 스캔한 코드의 내용(값), 스캔 시각, 회원 번호
- 세션 정보: 세션 ID, 세션 이름, 공개 여부, 세션 비밀번호(설정한 경우, 해시로 저장), 생성·최근 활동 일시

**주의:** 새 세션은 기본으로 **공개**입니다. 공개 세션은 세션 주소(링크)를 아는 사람이면 누구나 웹에서 스캔 내용을 볼 수 있습니다. 개인정보나 민감한 내용이 담긴 코드를 전송할 때는 세션을 비공개로 바꾸거나 비밀번호를 설정해 주세요.

### 2-3. 사용 분석 (Firebase Analytics)

앱 개선을 위해 Google의 Firebase Analytics로 다음 정보를 수집합니다.

- 앱 인스턴스 ID(앱 설치마다 Firebase가 만드는 식별자), 화면 조회, 기능 사용 이벤트(예: 스캔·생성한 코드의 **종류**와 형식, 저장·공유 방법, 설정 변경, 오류 유형)
- Firebase가 자동으로 수집하는 기기 모델, 운영체제와 버전, 앱 버전, 언어, 대략적인 국가·지역(IP 주소 기반), 첫 실행·세션 정보

스캔하거나 만든 코드의 **내용**, 이메일, 이름은 분석 정보로 보내지 않으며, 광고 ID는 수집하지 않습니다. Android에서는 기본으로 켜져 있고, iOS에서는 사용자가 켜기 전까지 수집하지 않습니다. 설정 → 앱 정보 및 지원 → 사용 분석 동의에서 끄면 그때부터 수집을 멈춥니다.

### 2-4. 위치 (선택)

- **위치 QR 코드 만들기:** 지도 화면에서 '현재 위치'를 누를 때만 위치 권한을 요청하고, 앱이 화면을 보고 있는 동안에만 기기의 현재 위치를 확인합니다. 백그라운드 위치는 사용하지 않습니다. 이 위치는 지도와 사용자가 만드는 QR 코드에만 쓰이며 회사 서버로 보내지 않습니다.
- **장소 검색:** 지도에서 장소를 검색하면 검색어와 현재 지도 중심 좌표(현재 위치일 수 있음)가 Google Maps Platform(Places·Geocoding)으로 전송됩니다. 좌표를 주소로 바꾸는 기능은 기기의 기본 위치 서비스(Android는 Google, iOS는 Apple)를 이용합니다.
- **Wi-Fi QR로 연결(Android):** Android가 Wi-Fi 연결에 위치 권한을 요구하기 때문에 요청하며, 앱은 이때 위치 정보를 수집하지 않습니다.

### 2-5. 기기 권한과 기기 안에서만 처리하는 정보

다음 권한은 해당 기능을 쓸 때만 요청하며, 거부해도 나머지 기능은 쓸 수 있습니다. 아래 정보는 회사 서버로 전송하지 않습니다(실시간 서버 전송을 켠 경우의 스캔 값은 2-2 참고).

- **카메라:** QR·바코드 스캔. 카메라 영상은 기기에서 바로 분석합니다. '스캔 사진 저장' 설정이 켜져 있으면 스캔 순간의 사진을 앱 내부 저장 공간에만 보관하며, 설정에서 끌 수 있습니다.
- **사진:** 만든 QR 코드나 스캔 이미지를 갤러리에 **저장**할 때만 사용합니다. 이미지에서 코드를 읽을 때는 시스템 사진 선택기로 사용자가 고른 사진만 기기에서 분석하며, 사진 보관함 전체를 읽지 않습니다.
- **연락처:** 연락처(vCard) QR을 사용자가 선택해 연락처에 추가할 때만 사용합니다. 기존 연락처를 읽거나 외부로 보내지 않습니다.
- **캘린더:** 일정 QR을 사용자가 선택해 캘린더에 추가할 때, 추가할 수 있는 캘린더 목록을 확인하고 일정을 씁니다. 일정 내용을 외부로 보내지 않습니다.
- **NFC:** NFC 태그를 읽어 스캔 기록에 저장합니다.
- **알림:** 복권 추첨일 알림 등 기기에서 예약하는 알림에만 사용합니다.
- **생체 인증(Face ID·지문):** 앱 잠금 해제에 운영체제 기능을 이용하며, 앱은 생체 정보를 받지도 저장하지도 않습니다.
- **Wi-Fi 상태 확인·변경:** Wi-Fi QR로 네트워크에 연결할 때 사용합니다.

### 2-6. 백업 (선택)

- **Google 드라이브 백업:** 사용자가 백업·복원을 실행할 때 사용자 본인의 Google 드라이브에 설정과 스캔 기록 백업 파일(JSON)을 저장하고, 복원할 때 그 백업 파일을 찾아 읽습니다. 백업 파일은 회사 서버를 거치지 않으며 회사는 그 내용에 접근하지 않습니다.
- **iCloud(iOS):** iCloud를 사용 중이면 앱 데이터가 사용자 본인의 iCloud에 동기화·백업될 수 있습니다. 이 역시 회사 서버를 거치지 않습니다.

### 2-7. 사용자가 직접 설정한 외부 전송

- **스캔 URL 연동·상품 검색:** 사용자가 이 기능을 켜고 주소나 검색 사이트를 지정하면, 스캔한 코드 값이 그 웹사이트로 전달됩니다. 전달된 정보는 해당 웹사이트의 개인정보 처리방침을 따릅니다.
- **복권 당첨 확인:** 동행복권 웹사이트에 회차 번호만 조회하며 개인정보는 보내지 않습니다.

### 2-8. 서비스 이용 중 자동으로 생성되는 정보

서버에 접속하는 과정에서 IP 주소, 접속 일시, 요청 기록 등 접속 기록이 서버 운영 환경에 남을 수 있습니다. 이 정보는 보안과 장애 대응에만 사용합니다.

## 3. 개인정보의 처리 목적

- 회원 식별, 로그인 유지, 계정 관리와 본인 확인(비밀번호 재설정 메일 발송 포함)
- 실시간 서버 전송 세션 생성과 스캔 데이터 표시·관리
- 기능 잠금 해제 상태를 기기 간에 유지
- 앱 사용 통계 분석, 오류 파악과 서비스 개선(사용 분석에 동의한 경우)
- 위치 QR 코드 생성을 위한 장소 검색과 지도 표시
- 부정 이용 방지, 보안, 문의 응대

## 4. 보유 및 이용 기간

- **회원 정보:** 회원 탈퇴 시까지 보유합니다. 탈퇴하면 즉시 로그인이 차단되고 로그인 토큰이 삭제되며, 남은 계정 정보는 탈퇴일로부터 30일 이내에 영구 삭제합니다.
- **실시간 서버 전송 데이터(세션·스캔 값):** 사용자가 세션이나 스캔을 삭제할 때까지 보유합니다. 웹 대시보드에서 삭제한 세션은 휴지통에 30일간 보관되어 그 사이 복구할 수 있고, 이후 영구 삭제할 수 있습니다. 회원 탈퇴 시에는 탈퇴일로부터 30일 이내에 함께 영구 삭제합니다.
- **기능 잠금 해제 기록:** 회원 탈퇴 시까지 보유하며, 탈퇴일로부터 30일 이내에 삭제합니다.
- **사용 분석 정보:** Firebase(Google 애널리틱스)에 설정된 보존 기간이 지나면 자동으로 삭제됩니다.
- **기기 안의 정보(스캔 기록·사진·설정):** 사용자가 앱에서 삭제하거나 앱을 삭제할 때까지 기기에 남습니다. 회사는 이 정보에 접근할 수 없습니다.
- 관계 법령에 따라 보존해야 하는 정보가 있으면 그 법령이 정한 기간 동안만 분리해 보관합니다.

## 5. 개인정보의 파기 절차와 방법

보유 기간이 끝나거나 처리 목적을 달성한 개인정보는 지체 없이 파기합니다. 서버 데이터베이스에 저장된 정보는 복구할 수 없도록 삭제하며, 종이 문서로 출력한 개인정보는 없습니다.

## 6. 개인정보의 제3자 제공

회사는 이용자의 개인정보를 제3자에게 제공하지 않습니다. 다만 이용자가 직접 공개로 설정한 실시간 세션은 링크를 아는 사람이 볼 수 있으며, 법령에 따라 수사기관 등이 적법한 절차로 요구하는 경우에는 예외로 합니다.

## 7. 개인정보 처리 위탁과 국외 이전

회사는 서비스 제공을 위해 다음 업체의 서비스를 이용합니다. 아래 업체로 정보가 전송될 때는 앱 이용 중 암호화된 네트워크(HTTPS)로 전송됩니다.

- **Google LLC (미국)**
  - Firebase Analytics: 2-3의 사용 분석 정보 / 앱 사용 분석 / 보존 기간 설정에 따라 삭제
  - Google Maps Platform: 장소 검색어, 지도 중심 좌표 / 장소 검색과 지도 표시 / 요청 처리 후 Google 정책에 따름
  - Google 로그인: 2-1의 Google 계정 정보 / 로그인 인증 / 회원 탈퇴 시까지
  - 문의처: [Google 개인정보처리방침](https://policies.google.com/privacy)
- **Apple Inc. (미국, iOS)**
  - Apple로 로그인: 2-1의 Apple 계정 정보 / 로그인 인증 / 회원 탈퇴 시까지
  - 문의처: [Apple 개인정보처리방침](https://www.apple.com/legal/privacy/)
- **서버 호스팅 사업자:** scanview.app 서버와 데이터베이스 운영(회원 정보, 실시간 서버 전송 데이터 보관) / 위탁 계약 종료 또는 회원 탈퇴 시까지

이용자는 사용 분석을 끄거나 해당 기능(로그인, 장소 검색)을 쓰지 않는 방법으로 국외 이전을 거부할 수 있습니다. 이 경우 해당 기능만 쓸 수 없고 나머지 기능은 그대로 쓸 수 있습니다.

## 8. 이용자의 권리와 행사 방법

이용자는 언제든지 자신의 개인정보를 열람·정정·삭제하거나 처리 정지를 요구할 수 있습니다.

- **열람·정정:** 앱의 설정 → 프로필(계정 설정)에서 이름(닉네임)을 확인·수정하고 비밀번호를 바꿀 수 있습니다.
- **삭제(회원 탈퇴):** 설정 → 프로필(계정 설정) → 위험 영역 → 회원탈퇴. 앱을 쓸 수 없으면 [계정 및 데이터 삭제 안내](https://scanview.app/legal/account-deletion)에 따라 이메일로 요청할 수 있습니다.
- **사용 분석 거부:** 설정 → 앱 정보 및 지원 → 사용 분석 동의를 끕니다.
- **권한 철회:** 기기 설정에서 카메라·위치·사진·연락처·캘린더·알림 권한을 언제든 끌 수 있습니다.
- 그 밖의 요청은 아래 이메일로 보내 주시면 본인 확인 후 지체 없이(늦어도 10일 이내) 조치 결과를 알려 드립니다. 법정대리인이나 위임을 받은 사람을 통해서도 요청할 수 있습니다.

## 9. 만 14세 미만 아동

서비스는 만 14세 미만 아동을 대상으로 하지 않으며, 만 14세 미만 아동의 개인정보를 알면서 수집하지 않습니다. 만 14세 미만 아동이 회원가입한 사실을 알게 되면 해당 계정과 정보를 지체 없이 삭제합니다.

## 10. 개인정보의 안전성 확보 조치

- 앱과 서버 사이의 모든 통신을 HTTPS·WSS로 암호화
- 비밀번호와 세션 비밀번호는 복원할 수 없는 해시로만 저장
- 기기에 저장하는 로그인 정보는 운영체제의 보안 저장소(Keychain·Keystore)에 보관
