## 한국어 (기본 언어)

### 앱 이름
QR 스캐너 - 바코드·재고 실사

### 짧은 설명
QR·바코드·데이터 매트릭스를 빠르게 읽고, 기록·재고 실사·코드 생성까지 한 앱에서.

### 자세한 설명
현장에서 쓰는 QR·바코드 스캐너입니다. 장비 명판에 새긴 작은 데이터 매트릭스, 멀리 있는 물류 바코드, 라벨이 빽빽한 선반까지 빠르고 정확하게 읽습니다.

■ 빠르고 정확한 인식
• QR, 데이터 매트릭스, PDF417, Aztec, Code 128·39·93, EAN-13·8, UPC-A·E, ITF-14, Codabar 등 13종 이상
• 어두운 바탕에 밝게 새긴(레이저 각인) 코드도 인식
• 1D 바코드는 여러 번 같은 값이 나와야 저장해 오독을 줄임
• 사진첩 이미지에서 코드 읽기

■ 원하는 것만 찍기
• 스캔 영역: 가운데 사각형 · 가로 띠 · 직접 지정(크기와 위치를 dp 단위로)
• 영역 밖 코드는 찍히지 않아 옆 라벨이 같이 찍히는 일이 없음
• 한 개 / 여러 개 / 연속 스캔을 스캔 화면에서 바로 전환

■ 현장 업무 기능
• 재고 실사: 예상 목록(엑셀에서 붙여넣기)과 스캔을 맞춰 일치·부족·누락·초과를 실시간 집계, 차이 보고서 CSV
• GS1 해석: GTIN·로트·유통기한·수량 자동 분리
• 라벨 카테고리: 구분자로 나뉜 라벨 값을 필드 이름으로 정리
• 스캔 규칙: 조건에 맞는 코드를 자동으로 그룹 저장·건너뜀·복사·URL 열기
• 수량 누적, 스캔별 메모, 위치 기록
• 볼륨 키로 스캔 확정(Android)
• 실시간 서버 전송(로그인 시)

■ 기록과 코드 생성
• 그룹별 스캔 기록, 검색, CSV·TXT 내보내기
• QR 코드(URL·텍스트·WiFi·연락처·이메일·SMS·전화·위치·일정)와 바코드 생성
• QR 색상·모양·로고 꾸미기, 고해상도 저장
• 백업과 복원

■ 편하게

• 회원가입 없이 바로 사용, 스캔 기록은 기기에 저장

## English (en-US)

### App name
QR Scanner & Stocktake

### Short description
Fast QR, barcode & Data Matrix scanning with history, stocktake and code maker.

### Full description
A QR & barcode scanner built for real work. It reads tiny laser-engraved Data Matrix codes on equipment nameplates, far-away logistics barcodes, and crowded label shelves — fast and accurately.

■ Fast, accurate scanning
• 13+ formats: QR, Data Matrix, PDF417, Aztec, Code 128/39/93, EAN-13/8, UPC-A/E, ITF-14, Codabar and more
• Reads light-on-dark (laser-engraved) codes
• 1D barcodes are confirmed over several frames to avoid misreads
• Scan codes from photos in your gallery

■ Scan only what you aim at
• Scan area: center square, horizontal band, or custom (size and position in dp)
• Codes outside the area are ignored, so neighboring labels don't get scanned
• Switch single / multiple / continuous scanning right on the scan screen

■ Built for the field
• Stocktake: paste your expected list (from Excel) and see matched, short, missing and over counts live; export a difference report as CSV
• GS1 parsing: GTIN, lot, expiry and quantity split automatically
• Label categories: name the fields of delimiter-separated labels
• Scan rules: auto-save to a group, skip, copy or open a URL when a code matches
• Quantity counting, per-scan notes, location tagging
• Confirm scans with the volume keys (Android)
• Real-time upload to your server (sign-in required)

■ History & code maker
• Scan history by group, search, CSV/TXT export
• Create QR codes (URL, text, Wi-Fi, contact, email, SMS, phone, location, event) and barcodes
• Style QR colors, shapes and logos; save in high resolution
• Backup & restore

■ Comfortable to use
• Dark mode; Korean, English, Japanese, Chinese, Spanish
• No sign-up needed; scan history stays on your device

Contact: support@scanview.app
